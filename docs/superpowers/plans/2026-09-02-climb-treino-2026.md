# CLIMB Treino 2026 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Salvar automaticamente cada treino concluído numa base Cloudflare D1 e permitir que o agente importe apenas as pendências para o vault.

**Architecture:** O app estático mantém uma outbox no `localStorage` e envia registros idempotentes para um Worker. O Worker valida o corpo, fixa o identificador do projeto e grava em D1; leitura e processamento acontecem somente pela CLI autenticada no Mac. Frontend, backend, migrações, testes e documentação vivem no mesmo repositório renomeado.

**Tech Stack:** HTML/JavaScript sem framework, TypeScript, Cloudflare Workers, D1/SQLite, Wrangler 4.128+, Vitest 4.1+ e `@cloudflare/vitest-plugin`.

**Spec:** `docs/superpowers/specs/2026-09-02-climb-treino-2026-design.md`

## Global Constraints

- Nome canônico em todas as camadas: `climb-treino-2026`.
- O app não abre nem escreve diretamente no Obsidian.
- O cache do navegador nunca é a fonte oficial depois que o Worker confirma a gravação.
- A outbox preserva o payload antes de qualquer chamada de rede e reenvia automaticamente.
- Nenhuma chave administrativa ou segredo entra no HTML, GitHub ou vault.
- Apenas `POST /v1/workouts` e `GET /health` ficam públicos.
- A leitura e a marcação de pendências usam Wrangler autenticado neste Mac.
- O Worker usa `compatibility_date: "2026-09-02"`; Node.js compatibility já é padrão nessa data e não recebe flag redundante.
- Registros remotos de teste são removidos ao final da verificação.

- [ ] **Step 3: Implement the minimal UMD outbox module**

Keep browser and CommonJS exports. Define:

```js
const OUTBOX_KEY = "climb-treino-2026::outbox";

function createWorkoutPayload({ session, state, logText })
function enqueueWorkout(storage, payload)
async function flushOutbox(storage, send)
function pendingCount(storage)
```

`flushOutbox` reads the array once, awaits each send sequentially, removes only confirmed IDs, persists after each confirmation, and returns `{ sent, pending }`. Corrupt JSON is treated as an empty array and overwritten on the next enqueue.
